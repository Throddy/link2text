# link2text

Видео в текст локально, без облачных API и подписок. Кидаешь ссылку или кладёшь файл рядом со скриптом, получаешь расшифровку.

Ссылки работают с YouTube, VK Видео, Rutube, Telegram, TikTok и ещё больше чем тысячей сайтов: скрипт сам понимает, откуда ссылка, и скачивает только звуковую дорожку. Речь распознаётся моделью Whisper прямо на Mac с Apple Silicon.

```
$ python link2text.py
Нашёл файлы рядом со скриптом (1):
  Лекция 5.mp4

=== Файл: Лекция 5.mp4 ===
Модель: mlx-community/whisper-large-v3-turbo
Язык: ru. Время: 212.4 с, x16.9 от реального времени

Готово! Папка с результатом: output/Лекция 5
  Лекция 5.txt
  Лекция 5.srt

Вставь ссылку или перетащи файл в это окно и нажми Enter.
Пустая строка или Ctrl+C завершают работу.

> https://vkvideo.ru/video-12345_67890

=== VK Видео ===
...
```

## Структура репозитория

```
link2text/
├── link2text.py        # главный скрипт: ссылки, файлы, папки → текст
├── download_audio.py   # скачивание аудио по ссылке (yt-dlp), работает и отдельно
├── transcribe.py       # распознавание речи (mlx-whisper), работает и отдельно
├── requirements.txt    # зависимости Python
├── .gitignore          # не пускает в репо медиа, результаты и cookies
├── README.md
│
├── *.mp4, *.mp3, ...   # ← сюда кладёшь свои видео и аудио (в git не попадают)
└── output/             # создаётся сам, в git не попадает
    └── <название>/
        ├── <название>.mp3   # только для ссылок: скачанное аудио
        ├── <название>.txt   # текст, каждая фраза с новой строки
        └── <название>.srt   # субтитры с таймкодами
```

`link2text.py` только решает, что пришло на вход, и вызывает функции из двух других модулей. Поэтому каждый модуль можно запускать и сам по себе.

## Как это устроено

```
ссылка ──► yt-dlp ──► лучшая аудиодорожка ──► ffmpeg ──► .mp3 ──┐
                                                                 ├──► mlx-whisper ──► .txt / .srt
файл (.mp4, .mov, .mp3, ...) ────────────────────────────────────┘
```

- **yt-dlp** знает, как достать медиа с каждого сайта, поэтому код не завязан на конкретный сервис. Видеопоток не скачивается, только звук: это быстрее и экономит трафик.
- **Локальные файлы** идут в Whisper напрямую. Whisper открывает их через ffmpeg, который сам вытаскивает звук из любого видео, так что промежуточный mp3 не нужен, а исходный файл остаётся нетронутым.
- **mlx-whisper** запускает Whisper на GPU Apple Silicon через фреймворк MLX от Apple, в float16. Это заметно быстрее оригинального `openai-whisper`, который на Mac по сути работает на CPU.

## Установка

Нужен Mac на Apple Silicon (M1 и новее) и Python 3.10+.

```bash
git clone https://github.com/Throddy/link2text.git
cd link2text

python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
brew install ffmpeg
```

При первом распознавании модель скачается с Hugging Face (turbo весит около 1.6 ГБ) и дальше будет браться из кеша.

## Использование

### Файлы рядом со скриптом

Положи видео или аудио в папку `link2text/` и запусти:

```bash
python link2text.py
```

Скрипт найдёт все медиафайлы в своей папке (и в текущей, если запускаешь из другого места), расшифрует их по очереди и потом перейдёт в интерактивный режим. Уже расшифрованные файлы при следующем запуске пропускаются, чтобы переделать их, добавь `--force`.

Поддерживаются `mp4, mov, mkv, webm, avi, m4v, flv, wmv, ts, mp3, m4a, wav, ogg, opus, flac, aac, wma`.

### Интерактивный режим

После обработки файлов скрипт ждёт ввода. Можно:
- вставить ссылку на видео;
- перетащить файл из Finder прямо в окно Терминала (путь подставится сам);
- перетащить папку, тогда расшифруются все медиафайлы в ней.

Пустая строка или `Ctrl+C` завершают работу.

### Всё аргументами

```bash
python link2text.py "https://youtu.be/..."                  # ссылка
python link2text.py lecture.mp4 ~/Downloads/interview.mov   # файлы
python link2text.py ~/Desktop/записи/                       # вся папка
python link2text.py "https://..." video.mp4 --model large --lang auto
```

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `--model` | `turbo` | модель Whisper: `turbo`, `large`, `medium`, `small`, `base` |
| `--lang` | `ru` | язык речи (`ru`, `en`, ...) или `auto` |
| `--formats` | `txt srt` | какие файлы сохранить |
| `--out` | `output` | куда складывать результаты |
| `--force` | | расшифровать заново то, что уже готово |
| `--bitrate` | `128` | битрейт mp3 для ссылок; для распознавания выше не нужно |
| `--cookies-from-browser` | | взять cookies из браузера, см. ниже |
| `--cookies` | | взять cookies из файла `cookies.txt`, см. ниже |
| `--delete-audio` | | удалить скачанный mp3 после распознавания |

### Отдельные модули

```bash
# Только скачать аудио (любая ОС, mlx не нужен)
python download_audio.py "https://rutube.ru/video/..." music --bitrate 320

# Только распознать файл
python transcribe.py lecture.mp3 --model large
```

## Какую модель выбрать

| Модель | Когда брать |
|---|---|
| `turbo` | по умолчанию; почти как `large`, но в несколько раз быстрее |
| `large` | важна каждая буква: термины, имена, плохой звук |
| `medium` | быстрее, качество чуть ниже |
| `small`, `base` | черновая расшифровка, очень быстро |

На M4 Pro модель `turbo` обрабатывает час записи примерно за несколько минут.

## Видео, которые требуют входа

Закрытые видео VK, Instagram, «подтвердите возраст» на YouTube и т.п. скачиваются только от имени залогиненного пользователя. yt-dlp умеет взять cookies из браузера, где ты уже вошёл в аккаунт, ничего вводить не нужно.

### Какой браузер указать

| Браузер | Флаг | Что нужно сделать на macOS |
|---|---|---|
| Safari | `--cookies-from-browser safari` | один раз дать Терминалу полный доступ к диску (ниже) |
| Chrome | `--cookies-from-browser chrome` | при первом запуске нажать «Разрешать всегда» в окне связки ключей |
| Firefox | `--cookies-from-browser firefox` | ничего, работает сразу |
| Edge | `--cookies-from-browser edge` | как у Chrome |
| Brave | `--cookies-from-browser brave` | как у Chrome |
| Opera | `--cookies-from-browser opera` | как у Chrome |
| Vivaldi | `--cookies-from-browser vivaldi` | как у Chrome |
| Яндекс Браузер, Arc | `--cookies cookies.txt` | yt-dlp их не читает напрямую, нужен файл (ниже) |

**Safari.** Safari хранит cookies в защищённой папке, и macOS не пускает туда Терминал без разрешения. Открой «Системные настройки» → «Конфиденциальность и безопасность» → «Полный доступ к диску», добавь туда Терминал (или iTerm, или VS Code, если запускаешь из него) и перезапусти его.

**Chrome и браузеры на его основе** (Edge, Brave, Opera, Vivaldi) шифруют cookies ключом из связки ключей macOS. При первом запуске появится окно с вопросом про доступ к «Chrome Safe Storage»: введи пароль от мака и нажми «Разрешать всегда».

**Несколько профилей в браузере.** По умолчанию берётся основной профиль. Если ты залогинен в другом, укажи его через двоеточие:

```bash
--cookies-from-browser "chrome:Profile 1"
```

Имя профиля видно на странице `chrome://version` в строке «Путь к профилю», это последняя папка в пути (`Default`, `Profile 1`, ...). Для Firefox то же самое смотри на `about:profiles`.

**Яндекс Браузер, Arc и остальные.** Установи в браузер расширение, которое сохраняет cookies в формате Netscape, например «Get cookies.txt LOCALLY» (ставится из Chrome Web Store, работает и в Яндексе, и в Arc). Открой нужный сайт, где ты залогинен, нажми на расширение, сохрани файл в папку проекта как `cookies.txt` и запусти:

```bash
python link2text.py "https://vk.com/video..." --cookies cookies.txt
```

Файл cookies даёт доступ к твоему аккаунту, никому его не отправляй. В `.gitignore` он уже добавлен, так что в репо случайно не попадёт.

## Поддерживаемые сайты

Всё, что умеет yt-dlp: YouTube, VK Видео, Rutube, Дзен, Telegram (публичные каналы), TikTok, Instagram, X, Twitch, Одноклассники, Vimeo, SoundCloud и многие другие. Полный список:

```bash
yt-dlp --list-extractors
```

Если сайта нет в таблице `SERVICES` в `download_audio.py`, он всё равно скачается, просто в выводе вместо красивого названия будет домен.

## Если что-то не работает

- **Сайт перестал скачиваться.** Сервисы часто меняют внутреннее устройство, а yt-dlp быстро под это подстраивается. Обнови его: `pip install -U yt-dlp`.
- **`Не найден ffmpeg`.** `brew install ffmpeg`.
- **Safari: `Operation not permitted`.** Терминалу не выдан полный доступ к диску, см. раздел про Safari выше.
- **Chrome: ошибка расшифровки cookies.** Скорее всего, в окне связки ключей была нажата «Запретить». Открой «Связку ключей», найди «Chrome Safe Storage» и на вкладке «Доступ» разреши его Терминалу.
- **Whisper повторяет одну фразу по кругу.** Обычно это музыка или тишина. В скрипте уже отключено опирание на предыдущий текст (`condition_on_previous_text=False`), что убирает большую часть таких случаев; если всё равно повторяет, попробуй `--model large`.
